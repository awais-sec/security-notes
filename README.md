# Security Notes

A structured cybersecurity knowledge base built from coursework, study material, and practical reference notes.

This repository is intended for **learning and reference**: understand a topic, revise the fundamentals, and use the notes as a starting point for deeper study. It complements the hands-on work in the rest of the portfolio rather than replacing it.

## Explore by Topic

| Area | What you'll find |
|---|---|
| **Forensics** | File systems, OS forensics, network forensics, mobile forensics, cloud forensics, and advanced digital forensics |
| **Incident Response** | Incident-response fundamentals, ransomware, threat intelligence, attack lifecycle, and response concepts |
| **Networking** | Networking fundamentals, OSI/TCP-IP, addressing, Ethernet, wireless, security, and troubleshooting |
| **Network Engineering** | Foundational network-engineering study material |
| **Shell Scripting** | Bash commands, conditionals, loops, functions, arrays, processes, and text manipulation |
| **Operating Systems** | OS fundamentals, processes, synchronization, memory management, and related concepts |
| **InfoSec Standards** | Information-security standards, governance, audit, and compliance material |
| **Investigation Techniques** | Fraud examination, document examination, interviewing, and investigative methods |
| **Legal** | Criminal procedure, investigation powers, evidence, AML, and accountability material |
| **Forensic Psychology** | Cybercrime behavior and forensic-psychology study material |
| **Cryptocurrency Investigations** | Cryptocurrency and blockchain investigation concepts |
| **Corporate Forensics** | Corporate and digital-forensics study material |
| **Counter-Terrorism** | Counter-terrorism related study material |
| **Miscellaneous** | Additional cybersecurity and computing topics that do not fit neatly elsewhere |

## About the Notes

The material comes primarily from university coursework, study material, and practical learning. Some notes have been reorganized or cleaned up for readability. They should be treated as **study/reference material**, not as authoritative legal, forensic, or security guidance.

Where a topic depends on a standard, law, vendor implementation, or rapidly changing technology, consult the current primary source before relying on the notes operationally.

## Repository Philosophy

The goal is simple: **keep useful learning material organized and accessible instead of letting it disappear after a course ends.**

The notes are preserved as a learning resource while the hands-on repositories demonstrate how those concepts are applied.
