# Network Engineering: MCQ Practice Questions

Self-test questions with answers and reasoning, as included in the original source material.

**1. What is the primary purpose of the Logical Link Control (LLC) sublayer in the Data Link Layer?**
Answer: Error detection and correction. The LLC sublayer manages error detection and correction and controls the flow of data over the network.

**2. Which topology requires termination at both ends of the main cable to prevent signal reflection?**
Answer: Bus topology (a linear bus requires terminators at both ends to prevent signal reflection).

**3. What is a significant advantage of the hybrid topology in large networks?**
Answer: Combines the benefits of multiple topologies. Hybrid topology combines the strengths of different topologies to optimize network performance.

**4. Which of the following services is typically provided by an Internet Service Provider (ISP)?**
Answer: DNS and DHCP services. ISPs provide services like DNS (resolving domain names) and DHCP (assigning IP addresses).

**5. Which layer of the OSI model is responsible for packet switching and route determination?**
Answer: Network Layer. The Network Layer handles packet routing and switching across different networks.

**6. In a wireless mesh network, what makes it self-healing?**
Answer: The network's capability to dynamically reroute data and maintain functionality.

**7. Which IEEE standard specifies the use of wireless access points in infrastructure networks?**
Answer: IEEE 802.11, the standard for wireless local area networks (Wi-Fi).

**8. What is the primary function of a storage-area network (SAN)?**
Answer: To provide block-level data storage. SANs are designed to provide centralized, high-speed block-level storage to connected servers.

**9. Which type of network is typically restricted to a single geographic location?**
Answer: LAN. LANs are confined to a limited geographic area, such as a building or campus.

**10. What is the purpose of ARP?**
Answer: Resolving IP addresses to MAC addresses. ARP (Address Resolution Protocol) maps IP addresses to MAC addresses within a network.

**11. What is a significant disadvantage of using a ring topology?**
Answer: Failure of one node disrupts the entire network. A break in the ring can halt all communication.

**12. Which protocol is responsible for ensuring reliable delivery of data over a network?**
Answer: TCP (Transmission Control Protocol) ensures data is delivered reliably.

**13. What type of signal transmission uses pulses of light?**
Answer: Optical transmission, typically in fiber optic cables.

**14. Which OSI layer is responsible for data encryption and decryption?**
Answer: Session Layer. Encryption and decryption are typically handled as part of the Session Layer for secure communication.

**15. What is the role of a network switch in a star topology?**
Answer: To act as the central connecting point. A switch serves as the hub in a star topology, connecting all devices.

**16. What is the primary distinction between a MAN and WAN?**
Answer: A Metropolitan Area Network (MAN) covers a city, while a Wide Area Network (WAN) spans countries or continents.

**17. What happens during the encapsulation process in the OSI model?**
Answer: Headers and trailers are added to the data as it moves down the OSI layers.

**18. In which network topology is every device connected to every other device?**
Answer: Mesh topology. All devices are interconnected for redundancy and reliability.

**19. What type of device connects multiple LANs and operates at the Network Layer of the OSI model?**
Answer: Router. A router connects multiple LANs and operates at Layer 3 (Network Layer).

**20. Which technology is used to assign private IP addresses to devices within a network and convert them to public IPs for internet communication?**
Answer: NAT (Network Address Translation) translates private IP addresses to public IP addresses, allowing devices in a private network to communicate over the internet.
