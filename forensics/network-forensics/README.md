# Network Forensics

Course material and coursework from Network Forensics (BS-DFCS), organized into three parts.

## Structure

- **[notes/](notes/README.md)** — 9 files covering network forensics fundamentals, investigation methodology, deep packet inspection, statistical flow analysis, tunneling/encryption, malware, C2 infrastructure, log analysis, and WLAN forensics.
- **[assignments/](assignments/README.md)** — CTF-style network forensics challenge writeups (DNS TXT beaconing, tracking-pixel exfiltration, ICMP/XOR covert channel).
- **[pcap/](pcap/README.md)** — 4 reference/practice packet captures, kept separately since they don't match the assignment's own evidence files.
