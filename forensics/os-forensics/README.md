# OS Forensics

Notes and hands-on labs covering Linux and Windows forensic artifacts, data carving, and file recovery.

## Contents

- `linux-forensics-and-file-systems.md` — Linux file system architecture, FHS, EXT file systems, and Linux forensic commands/log files
- `windows-artifacts-and-registry-reference.md` — Windows forensic commands, file paths, and registry keys reference
- `data-carving-and-recovery.md` — carving concepts, header/footer method, image naming conventions, timestamp analysis
- `imaging-and-carving-labs.md` — hands-on labs: creating a USB image in Linux, and recovering a deleted JPEG from a raw `.dd` image
