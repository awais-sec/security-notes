# Advanced Forensics

Course material and coursework from Advanced Digital Forensics (BS-DFCS, Sp-2023), organized into three parts.

## Structure

- **[notes/](notes/README.md)** — course notes on AD forensics, cloud forensics, web attack investigation, malware forensics, Autopsy, and Windows Registry artifact paths.
- **[assignments/](assignments/README.md)** — six submitted assignments covering NTFS artifacts, the Mantooth case, breach investigation log sources, SQL Server logging, NTLM vs Kerberos, and Man in the Cloud attacks.
- **[case-study/](case-study/README.md)** — the "Operation Phantom Click" case study prompt.

## Not Included

The course's "Digital Forensics Overview" lecture deck (165 slides, instructor-authored) is left out of this upload — it's the instructor's material rather than original notes or coursework, and is largely image-based.
