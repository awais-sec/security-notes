# Cloud Service Hijacking Using Social Engineering (and Related Attacks)

Expanded notes on the 10 cloud computing attacks listed in [cloud-forensics-overview.md](02-cloud-forensics-overview.md), with a one-line explanation for each.

1. **Service Hijacking using Social Engineering Attacks**: Attackers manipulate individuals (e.g., through phishing or pretexting) to gain unauthorized access to cloud services, allowing them to take control or steal data.
2. **Session Hijacking using XSS Attack**: Exploits cross-site scripting (XSS) vulnerabilities to steal session tokens, enabling attackers to hijack active user sessions in the cloud environment.
3. **Domain Name System (DNS) Attacks**: Involves manipulating DNS records (e.g., DNS spoofing) to redirect cloud service traffic to malicious sites, compromising data integrity or availability.
4. **SQL Injection Attacks**: Injects malicious SQL queries into cloud database inputs to manipulate or extract data, exploiting poorly secured database interfaces.
5. **Wrapping Attack**: Modifies SOAP (Simple Object Access Protocol) messages in transit to cloud services, allowing attackers to bypass authentication or alter requests.
6. **Service Hijacking using Network Sniffing**: Captures and analyzes network traffic to intercept sensitive data or credentials, enabling unauthorized access to cloud services.
7. **Session Hijacking using Session Riding**: Also known as cross-site request forgery (CSRF), this attack tricks users into executing unintended actions in their cloud sessions, giving attackers control.
8. **Side Channel Attacks or Cross-Guest VM Breaches**: Exploits shared resources in virtualized environments to extract data from co-located virtual machines (VMs), such as through timing or electromagnetic leaks.
9. **Cryptanalysis Attacks**: Attempts to break cryptographic systems used in the cloud to decrypt data or gain access, exploiting weak algorithms or keys.
10. **DoS and DDoS Attacks**: Denial-of-Service (DoS) or Distributed Denial-of-Service (DDoS) attacks overwhelm cloud resources with traffic, rendering services unavailable to legitimate users.
